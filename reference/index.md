# Package index

## Writing FCS Files

Export FAUST-identified populations to FCS files

- [`faust_fcs_write()`](https://satvilab.github.io/UtilsFaustSV/reference/faust_fcs_write.md)
  : Save FAUST subset as an FCS file

## Population Counts

Get and visualize counts of FAUST populations

- [`faust_count_get_pop()`](https://satvilab.github.io/UtilsFaustSV/reference/faust_count_get.md)
  [`faust_count_get()`](https://satvilab.github.io/UtilsFaustSV/reference/faust_count_get.md)
  : Get counts of subsets identified by FAUST
- [`faust_count_plot()`](https://satvilab.github.io/UtilsFaustSV/reference/faust_count_plot.md)
  : Plot counts of FAUST pops by sample

## Marker Information

Get information about markers used by FAUST

- [`faust_marker_get_usage()`](https://satvilab.github.io/UtilsFaustSV/reference/faust_marker_get_usage.md)
  : Get the number of levels used for each marker FAUST used to cluster
