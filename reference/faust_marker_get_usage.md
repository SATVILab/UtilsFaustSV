# Get the number of levels used for each marker FAUST used to cluster

Gives the markers FAUST used and the number of levels used per such
marker. Note that it only works after the SCAMP clustering has been
performed, i.e. not simply after the annotations have been approved.

## Usage

``` r
faust_marker_get_usage(project_path)
```

## Arguments

- project_path:

  character. FAUST project directory.

## Value

`Character vector`
